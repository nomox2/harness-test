# CourtView Harness — 게이트 & 판정 스크립트 (R5)

| 항목 | 내용 |
|---|---|
| G1 재개 방식 | 터미널에서 `y` 입력 |
| G2 재개 방식 | 내가 관계자 확인 후 터미널에서 `y` 입력으로 대리 승인 |
| A5 검토 항목 | DESIGN.md 색상 토큰 외 하드코딩 hex값만 검토 |
| 판정 결과 저장 | `Harness/gate-report.md` — 위반 목록 + 통과/실패 결론 |

## 게이트 동작 흐름

```
A2 완료
  → 하네스 일시정지
  → "분석·설계 초안을 확인하세요. 계속하려면 y를 입력하세요."
  → y 입력 → A3 시작

A3 완료
  → 하네스 일시정지
  → "키스크린을 관계자에게 공유하세요. 컨펌 후 y를 입력하세요."
  → y 입력 → A4 시작
```

## A5 판정 기준

- DESIGN.md에 정의된 토큰 이름 목록 추출
- 산출물 파일에서 `#` 으로 시작하는 hex값 탐색
- 토큰으로 참조되지 않은 hex값이 1개 이상 → **위반**
- 위반 0개 → **통과**
