## 레퍼런스에서 발견한 패턴

### 통계·리포트 화면 (달다방, 워크온, 앳플리)

| 패턴 | 관찰 내용 |
|---|---|
| 지표 표시 방식 | 수치 + 단위를 큰 글씨로 상단에 배치, 하위 항목은 리스트로 나열 |
| 탭 구조 | 상단 탭으로 카테고리(슈팅/드리블/리바운드) 전환 |
| 차트 | 선 그래프로 최근 기록 추이 표시, 날짜 축 필수 |
| 상태 처리 | 데이터 없을 때 빈 화면 + 안내 문구로 명확히 구분 |

### 커뮤니티 화면 (달다방, 워크온, Gentler Streak)

| 패턴 | 관찰 내용 |
|---|---|
| 탐색 구조 | 검색 바 + 칩 필터로 카테고리 좁히기 |
| 목록 표시 | 카드형 리스트, 썸네일·제목·날짜 기본 구성 |
| 마이 커뮤니티 | 가입한 그룹을 마이페이지에서 별도 탭으로 관리 |

## CourtView 반영 포인트

### 분석 결과 화면 (핵심)
- 슈팅·드리블·리바운드 탭을 상단에 배치, 탭 전환 시 해당 영역 데이터만 표시 (MA01)
- 최근 5개 결과를 선 그래프로 표시, x축 날짜 필수 (MA02)
- 원형 지표는 실제 값에 비례한 fill로 표현, 분모 0이면 "계산 불가" 표기 (§6)
- 분석 불가 항목은 임의 점수 없이 "분석 불가" 상태로 명시 (제약 1)

### 커뮤니티 화면
- 검색 바 + 카테고리 칩 필터 조합
- 게시물 목록은 카드형, 비회원도 목록 열람 가능 (AC01)
- 마이페이지에서 My Nets 별도 탭으로 접근

### 다크 배경 적용
- PRD §7: 검은 배경, 오렌지 액센트, 라운드 컨테이너, 원형 지표
- DESIGN.md canvas-night(`#121212`) 적용
