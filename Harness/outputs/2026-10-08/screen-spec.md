## 화면 1 — 모션 분석 결과

**목적:** 슈팅·드리블·리바운드별 최근 분석 결과와 피드백 확인

### 레이아웃

```
[ 상단 네비게이션 ]
  ← 분석 결과        [아이콘]

[ 스킬 탭 ]
  슈팅 | 드리블 | 리바운드   ← 탭 (선택 탭: 텍스트 + 액센트 컬러 밑줄)

[ 분석 모드 스위치 ]
  [ 모션 분석 ●] [ 게임 분석  ]   ← 토글 스위치

[ 최근 결과 차트 ]
  선 그래프 — 최근 5개 결과
  x축: 날짜, y축: 점수
  선택한 포인트 강조 표시

[ 선택 결과 상세 ]
  전체 점수: OO점
  ─────────────────
  평가 항목 1: 값 / 상태
  평가 항목 2: 값 / 상태
  평가 항목 3: 분석 불가  ← 폐색·화질 불량 시 임의 점수 없이 이 상태로

[ 피드백 ]
  관찰된 동작 |  개선 포인트 | 다음 훈련 액션

[ 하단 네비게이션 ]
```

### 상태
| 상태 | 표시 |
|---|---|
| 결과 없음 | 빈 화면 + "분석 기록이 없습니다" + 영상 추가 진입점 |
| 처리 중 | 현재 처리 단계 표시, 점수 미표시 |
| 분석 불가 항목 | "분석 불가" 텍스트, 점수 없음 |

## 화면 2 — 게임 분석 결과

**목적:** 슈팅·드리블·리바운드별 게임 지표 9개 확인

### 레이아웃

```
[ 상단 네비게이션 ]
[ 스킬 탭 ] — 슈팅 | 드리블 | 리바운드
[ 분석 모드 스위치 ] — [ 모션 분석  ] [ 게임 분석 ●]

[ 집계 범위 표시 ]
  게임: OO전  |  기간: YYYY.MM.DD ~ MM.DD

[ 지표 3개 — 원형 인디케이터 ]
  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │  ○ fill  │  │  ○ fill  │  │  ○ fill  │
  │  OO%     │  │  OO%     │  │ 계산 불가 │
  │ 필드골%  │  │  3점%    │  │  자유투%  │
  └──────────┘  └──────────┘  └──────────┘
  성공/시도: N/N   성공/시도: N/N

[ 지표 정의 안내 ]
  각 지표명 옆 ? 아이콘 → 툴팁으로 정의 표시

[ 하단 네비게이션 ]
```

### 상태
| 상태 | 표시 |
|---|---|
| 분모 0 | "계산 불가" (0%와 구분) |
| 높을수록 좋지 않은 지표 (턴오버율) | 녹색 강조 없이 중립 색상 |

## 화면 3 — 커뮤니티 목록

**목적:** 공개 게시물 탐색, 비회원도 열람 가능

### 레이아웃

```
[ 상단 네비게이션 ]
  CourtView         🔍  🔔

[ 검색 바 ]
  [ 🔍 게시물, 넷 검색... ]

[ 카테고리 칩 필터 ]
  전체 | 슈팅 | 드리블 | 리바운드 | 넷 | ...

[ 게시물 카드 리스트 ]
  ┌─────────────────────────────┐
  │ [썸네일]  제목              │
  │           작성자 · 날짜     │
  │           ♥ 좋아요  💬 댓글 │
  └─────────────────────────────┘
  (반복)

[ 글쓰기 FAB ]   ← 로그인 회원만 활성화
  ＋

[ 하단 네비게이션 ]
  홈 | 분석 | 커뮤니티 | 넷 | 마이
```

### 상태
| 상태 | 표시 |
|---|---|
| 검색 결과 없음 | "결과가 없습니다" 빈 화면 |
| 비회원 글쓰기 시도 | 로그인 화면으로 이동, 완료 후 원래 화면 복귀 |
