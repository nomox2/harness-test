## 화면 1 — 모션 분석 · 슈팅

상단 탭: 슈팅 선택 / 모션 분석 활성  
최근 5개 결과 선 그래프 · 전체 점수 · 평가 항목 · 피드백

## 화면 2 — 게임 분석 · 슈팅

상단 탭: 슈팅 선택 / 게임 분석 활성  
원형 지표 3개: 필드골%, 3점%, 자유투%

## 화면 3 — 모션 분석 · 드리블

상단 탭: 드리블 선택 / 모션 분석 활성  
평가 항목: 크로스오버 각도, 드리블 리듬, 무게중심 이동  
분석 불가 항목은 "분석 불가" 표기

## 화면 4 — 게임 분석 · 드리블

상단 탭: 드리블 선택 / 게임 분석 활성  
원형 지표 3개: 턴오버율, 드라이브 성공률, 어시스트율  
턴오버율은 낮을수록 좋으므로 녹색 강조 없이 중립 표기

## 화면 5 — 모션 분석 · 리바운드

상단 탭: 리바운드 선택 / 모션 분석 활성  
평가 항목: 박스아웃 자세, 점프 타이밍, 공 확보 동작

## 화면 6 — 게임 분석 · 리바운드

상단 탭: 리바운드 선택 / 게임 분석 활성  
원형 지표 3개: 공격 리바운드율, 수비 리바운드율, 전체 리바운드율

## 화면 7 — 커뮤니티 목록

검색 바 + 카테고리 칩 필터  
게시물 카드 리스트 (PostCard 컴포넌트)  
비회원도 목록 열람 가능 / 글쓰기 FAB은 회원만 활성

## 화면 8 — 로그인

이메일 + 비밀번호 입력 필드  
로그인 버튼 (primary 컬러)  
계정 복구 링크 / 회원가입 진입점  
실패 시 에러 메시지 표시

## 화면 9 — 넷(Net) 탐색

지역 + 실력 수준 칩 필터  
넷 카드 리스트: 이름, 지역, 멤버 수, 실력 레벨  
인기 넷 / 새 넷 탭 구분

## 화면 10 — 마이페이지

프로필 이미지 + 이름  
My Nets, 내 게시물, 좋아요한 게시물 섹션  
설정 / 약관 진입점
