# CourtView — User Stories & Service Constraints

## User Stories

| # | 유저 스토리 |
|---|---|
| 1 | 농구 플레이어가 훈련·게임 영상을 업로드해 슈팅·드리블·리바운드 분석 결과를 받는다 |
| 2 | 농구 플레이어가 최근 분석 결과(최대 5개)를 차트로 확인하고 피드백을 읽는다 |
| 3 | 농구 플레이어가 모션 분석과 게임 분석 모드를 전환하며 슈팅·드리블·리바운드별 지표를 조회한다 |
| 4 | 가입 회원이 게시물을 작성·댓글·좋아요하고, 비회원(게스트)은 공개 게시물을 조회만 한다 |
| 5 | 회원이 지역·실력 수준으로 넷(Net)을 검색·가입하고 My Nets에서 내 넷 목록을 확인한다 |

## 어기면 안 되는 것

| # | 제약 | 근거 |
|---|---|---|
| 1 | 분석 불가 항목(폐색·화질 불량 등)에 임의 점수를 생성해 표시해서는 안 된다 | PRD §5 Scoring and Feedback Policy |
| 2 | 사용자는 자신의 영상과 분석 결과만 열람할 수 있어야 하며, 타인의 것에 접근할 수 없다 | PRD §7 Quality and Operational Requirements |
